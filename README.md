# مِداد · QuoteIt

منصّة عربية لنشر الاقتباسات وتصميمها، فيها مكتبة لعيون الشعر العربي — مشروع معسكر القمّة (مسار البرمجة والتطوير).

Laravel 13 · PHP 8.4 · Blade · Tailwind 4 · Vite · JavaScript · SQLite

## التشغيل

```bash
composer install
npm install
cp .env.example .env
php artisan key:generate
touch database/database.sqlite
php artisan migrate --seed
composer run dev
```

ثم افتح http://localhost:8000

`--seed` يضيف المكتبة (الشعراء والدواوين والأبيات) وبيانات تجريبية: 5 مستخدمين و20 اقتباساً مصمّماً مع إعجابات وردود.
حسابات التجربة: `sara@midad.test` · `khalid@midad.test` · `noura@midad.test` · `fahad@midad.test` · `reem@midad.test`، وكلمة المرور لها جميعاً `password`.

الاختبارات: `php artisan test`

## ما في المنصة

- **الأساسيات (SRS v1.2):** عرض الاقتباسات للجميع، إنشاء حساب، دخول وخروج، مشاركة اقتباس من 3 إلى 155 حرفاً، وتعديل وحذف الاقتباسات الخاصة فقط.
- **مرسم الحروف:** تصميم بطاقة الاقتباس (الخط، الألوان، ملمس الورق، المقاس، حجم الخط، إبراز الكلمات) مع معاينة مباشرة.
- **التصنيفات، القائل والكتاب، حكاية الاقتباس.**
- **نوع النص والمصدر:** «نقلته عن غيري» يُلزم بالقائل واسم المصدر (المادة ١٥ من نظام حماية حقوق المؤلف)، و«من تأليفي» بتوقيع يختاره الكاتب، و«مأثور» بلا قائل. الرابط اختياري ويظهر للقرّاء باسم المصدر.
- **عام أو خاص:** الاقتباس العام يراه الجميع، والخاص في ركن صاحبه وحده ولا يترك أثراً في أي مكان آخر. ويُعرض بطاقةً مصمّمة أو نصاً بين علامتي تنصيص.
- **الإعجاب والمحفوظات والردود، وصفحة الاقتباس مع «قد يعجبك أيضاً».**
- **البحث والترتيب والتصفية، اقتباس اليوم، والملف الشخصي.**
- **خزانة الأدب:** رفّ الدواوين والمعلقات السبع، رواق الشعراء، «لكلّ مقامٍ مقال»، جدار المأثورات؛ ويُنقل البيت المختار إلى مرسم الحروف مقفلاً ومنسوباً لقائله.
- **رفوف القرّاء:** صفحة لكل كتاب تجمع اقتباسات القرّاء منه، و«كتبي» (أقرؤه، قرأته، أريد قراءته).
- **ركني:** لون الركن، واقتباس مثبّت، و«بقلمي» لنصوص القارئ من تأليفه، و«مختاراتي» (مجموعات اقتباسات عامة أو خاصة)، و«شعرائي».
- **دواوين القرّاء:** ينقل القارئ أبيات شاعر ليس في الخزانة مع مصدرها؛ تبقى دفتراً خاصاً، ولا تُنشر للجميع إلا لشاعر تُوفّي قبل أكثر من ٥٠ سنة (نظام حماية حقوق المؤلف، المادة ١٩).
- الوضع الليلي، ونسخ الاقتباس، وواجهة متجاوبة حتى عرض 390px.

## نصوص المكتبة

الأبيات في `database/data/library.json`، وكل بيت فيها رُوجع آلياً مع نصوص ويكي مصدر.
النصوص من ويكي مصدر وويكي الاقتباس، ومتاحة بترخيص المشاع الإبداعي (CC BY-SA).

## خط ثمانية

ترخيص خط ثمانية لا يسمح بإعادة توزيع ملفاته، لذلك ليست ضمن المستودع.
حمّل الخط من صفحته الرسمية وضع ملفات `woff2` كما هي (بأسمائها الأصلية) في `resources/fonts/thmanyah/`.
بدونها يعمل الموقع بخطوط بديلة مفتوحة الترخيص (IBM Plex Sans Arabic، Amiri، Noto Naskh Arabic).
